# Из грязи в князи · 4.1

Мобильная браузерная игра о пути от крестьянина до королевского вельможи. Развивает исходную версию 4.0: пять земель, местные валюты, предприятия, работники, товары, торговля, караваны, поручения, репутация, титулы и экипировка.

## Запуск

Требуется Python 3; npm и сборка для игры не нужны.

```sh
cd /workspace/my-first-game
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте в браузере адрес сервера на порту 8000. Используйте HTTP: модули JavaScript не рассчитаны на открытие HTML через `file://`. На обычном статическом хостинге разместите `index.html`, `styles.css`, `src/` и `assets/` с сохранением путей и MIME JavaScript для `.mjs`. Сервер API, база данных, ключи и внешние CDN не требуются.

## Игровой цикл

Начните с нажатий на героя и огорода. Предприятие даёт деньги каждую секунду и товары на склад. Покупайте улучшения, нанимайте работников, продавайте товары или передавайте их по поручениям. Для каждой следующей земли нужны два поручения, четыре уважения и указанная сумма. Все открытые земли продолжают производить товары и валюту. Новая земля получает 80 единиц местной валюты; в замке первые пять монет для конюшни можно заработать вручную.

- Улучшение стоит `base × 1.62^level`; максимум 100 уровней.
- Найм оплачивается **один раз**, регулярной зарплаты нет. До пяти работников: каждый даёт +35% к денежному доходу и +20% к выпуску товаров. Увольнение бесплатно, плата за найм не возвращается. Это сохранённая модель исходной игры.
- Продажа использует только целые товары. Караван расходует десять единиц и приносит валюту следующей открытой земли; обмен валют берёт комиссию 10%.
- В мастерской каждой земли есть дополнительный рецепт. Сырьё расходуется атомарно, требуется предприятие готового товара. Базовое производство работает независимо: рецепты не блокируют развитие. Доски используются как топливо и материал.
- Купленные предметы сразу надеваются. Бонусы суммируются; предмет можно снять или продать за половину цены в текущей валюте. Повторная продажа ничего не начисляет.
- Поручения повторяются по пяти предприятиям; количество товара растёт каждые пять поручений. Для высшего титула нужны суммарное уважение и местная валюта.

## Сохранения

Ключ `localStorage` **`knyazi_rebuilt_v4`** и схема версии 4 сохранены. Поддерживаются существующие корректные сохранения 4.0, экспорт и импорт JSON. Рекомендуется скачать резервную копию перед обновлением. Origin, протокол и порт браузера определяют хранилище: смена адреса требует переноса JSON.

Начисления используют одну сохранённую временную отметку. Повторный вызов таймера, возврат во вкладку и перезагрузка не начисляют один период дважды. Максимум за один непрерывный перерыв — два часа. Импорт переносит записанный прогресс и начинает отсчёт с момента импорта, без дополнительного дохода по времени из файла. Некорректные числа ограничиваются, дубликаты предметов удаляются, неизвестная новая схема отклоняется. Повреждённая запись не перезаписывается автоматически: нужны явный сброс или восстановление JSON.

При наличии Web Locks активна одна игровая вкладка на origin. Вторая просит вернуться в первую или закрыть её и обновить страницу. В старых браузерах без Web Locks игра запускается с синхронизацией записей, но для надёжной игры следует держать одну вкладку. Локальное сохранение зависит от доступности хранилища браузера; при ошибке используйте экспорт. Это не защита от изменения файлов игроком и не облачная синхронизация.

## Проверки

Чистые тесты состояния требуют Node.js 18+ и не используют сторонние пакеты:

```sh
node --test tests/state.test.mjs
```

Для браузерных проверок нужен запущенный сервер, Python Playwright и Chromium. В подготовленной облачной среде они уже есть. В другой машине установите `python3 -m pip install playwright==1.62.0`, а Chromium установите штатным пакетным менеджером; при необходимости укажите путь через `CHROMIUM_PATH`.

```sh
python3 tests/browser_test.py
# другой порт или путь браузера:
GAME_TEST_URL=http://127.0.0.1:8000 CHROMIUM_PATH=/usr/bin/chromium python3 tests/browser_test.py
```

Тесты создают отдельные контексты и используют ускоренные часы; прогресс обычного пользователя не затрагивается. Доступ к тестовым функциям включается только параметром `?test`. Покрыты пять земель и высший титул, экономические действия и запреты, переработка, экипировка, JSON, офлайн-доход, повторное начисление, две вкладки, меню и размеры экрана 320–1280 px. Снимки текущего браузерного прогона сохраняются в `/tmp/game-mobile.png` и `/tmp/game-desktop.png`.

## Структура

- `src/data.mjs` — локации, цены, экипировка, рецепты.
- `src/state.mjs` — начальное состояние, проверка сохранений и единые часы.
- `src/game.mjs` — существующие механики, действия, интерфейс и браузерное хранение.
- `src/platform.mjs` — изолированная точка будущей интеграции платформ.
- `styles.css` — оформление книги и адаптация.
- `assets/characters/` — шесть отдельных SVG по титулам, одинаковый холст 120×160 и положение ног.
- `assets/buildings/` — пять самостоятельных SVG объектов на прозрачном фоне.

SVG — созданная для проекта базовая векторная графика. Это не готовые анимированные PNG-спрайты. Возможности расширения и ограничения: [отчёт](docs/IMPLEMENTATION.md).
